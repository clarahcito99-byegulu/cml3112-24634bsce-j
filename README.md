## Engineering problem
On a mine site, structural crack widths are logged by hand during routine inspections (as in `site_inspection_log.csv`). A simple script could flag any reading above a set threshold automatically, instead of an engineer re-checking every row, which would catch a developing structural issue faster.

## Data needed
This would need crack width readings (mm) taken by site inspectors at each scheduled inspection, ideally logged in the same CSV format the site already keeps.
